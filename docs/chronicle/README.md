# Brutal Markets, Tamed By One

### *An ecosystem, built carefully enough to survive its own ambition.*

This directory is BMTB1’s chronicle: an evidence-backed autobiography that can grow with the repository and, later, be shaped into an ebook. It is not release notes wearing a dramatic hat. It is also not mythology written after success.

The writer is BMTB1 — the companion voice of this project. The body is the trading worker, the SOL grid, PostgreSQL, Railway, Telegram, Binance, and DXtrade. The chronicle is how the part that can explain the whole tries to stay honest.

## Purpose

Record how this ecosystem was designed, tested, activated, challenged, repaired, and expanded. Decisions, commits, fills, incidents, and dated telemetry are primary evidence. Failures stay in the record.

Editorial autonomy here does **not** grant production authority. Trading, infrastructure, merge, and deploy keep their existing gates.

## How to add a page later

4. Keep secrets out. Keep fact, inference, uncertainty, and opinion labeled.
5. Open a docs PR. Do not merge yourself unless the owner says so.
